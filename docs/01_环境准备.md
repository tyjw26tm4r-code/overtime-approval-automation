# 环境准备指南

在开始部署之前，请先检查您的环境是否满足所有要求。

---

## ✅ 前置条件检查清单

### 1. Microsoft 365 许可证

**您需要什么？**
- Microsoft 365 商业版或企业版许可证
- 包含 Power Apps 和 Power Automate 的权限
- SharePoint Online 和 Exchange Online

**如何检查？**

**步骤 1：** 打开 [Microsoft 365 管理中心](https://admin.microsoft.com)
```
URL: https://admin.microsoft.com
```

**步骤 2：** 用公司账户登录

**步骤 3：** 左侧菜单点击 "用户" → "活跃用户"

**步骤 4：** 找到您的账户，点击打开

**步骤 5：** 向下滚动，查看"许可证和应用"部分

**检查清单：**
- [ ] Power Apps 许可证：显示 ✓（绿色勾选）
- [ ] Power Automate 许可证：显示 ✓（绿色勾选）
- [ ] SharePoint Online：显示 ✓（绿色勾选）
- [ ] Exchange Online：显示 ✓（绿色勾选）

**如果没有看到这些许可证？**
- 📞 联系您公司的 IT 部门或 Microsoft 365 管理员
- 要求为您启用这些服务
- 通常启用需要 5-15 分钟

---

### 2. 访问权限

**您需要什么？**
- SharePoint Online 管理员访问权限（或至少有创建 List 的权限）
- Power Apps 环境访问权限
- Power Automate 环境访问权限

**如何检查？**

#### 检查 SharePoint 权限

**步骤 1：** 打开 SharePoint 主页
```
URL: https://[your-company].sharepoint.com/
```

**步骤 2：** 点击左上角的"应用启动器"（9个点的网格图标）

**步骤 3：** 搜索或找到 "SharePoint"

**步骤 4：** 如果能打开 SharePoint，说明您有访问权限

**步骤 5：** 尝试创建一个新的 Team Site（站点）
- 点击 "+ 创建站点"
- 如果看到这个按钮，说明您有权限
- 如果没看到，联系 IT 部门申请权限

#### 检查 Power Apps 权限

**步骤 1：** 打开 Power Apps
```
URL: https://make.powerapps.com
```

**步骤 2：** 用公司账户登录

**步骤 3：** 左侧菜单点击 "应用"

**步骤 4：** 如果能看到应用列表，说明您有权限

**步骤 5：** 点击 "+ 新建应用" → "Canvas app"
- 如果能创建新应用，说明您有足够权限
- 如果没有，联系 IT 部门申请

#### 检查 Power Automate 权限

**步骤 1：** 打开 Power Automate
```
URL: https://make.powerautomate.com
```

**步骤 2：** 用公司账户登录

**步骤 3：** 左侧菜单点击 "我的流"

**步骤 4：** 点击 "+ 新建流"
- 如果能创建流程，说明您有足够权限
- 如果没有，联系 IT 部门申请

---

### 3. 网络连接

**您需要什么？**
- 稳定的互联网连接
- 能访问 Microsoft 365 服务（cloud.microsoft.com）
- 防火墙允许访问以下服务：
  - `*.microsoft.com`
  - `*.microsoftonline.com`
  - `*.office365.com`

**如何检查？**

**步骤 1：** 打开浏览器，尝试访问这些 URL：
```
https://portal.office.com
https://make.powerapps.com
https://make.powerautomate.com
https://admin.microsoft.com
```

**步骤 2：** 如果都能访问，网络连接没有问题

**步骤 3：** 如果某个 URL 无法访问或显示"无法连接"，说明可能有防火墙限制
- 📞 联系公司网络部门或 IT 部门
- 告诉他们您需要访问 Microsoft 365 服务

---

### 4. 浏览器要求

**推荐使用以下浏览器：**
- Microsoft Edge（最新版本）- **推荐** ⭐⭐⭐⭐⭐
- Google Chrome（最新版本）- **推荐** ⭐⭐⭐⭐
- Safari（最新版本，Mac）- **可用** ⭐⭐⭐
- Firefox（最新版本）- **可用** ⭐⭐⭐

**不推荐使用：**
- ❌ Internet Explorer（已过时，不支持）
- ❌ 过旧的浏览器版本

**如何更新浏览器？**
- Microsoft Edge：自动更新，检查方式 - 菜单 → 关于
- Chrome：菜单 → 关于 Chrome
- Safari：系统偏好设置 → 软件更新

---

### 5. 账户准备

**员工账户（用于审批）：**

您需要列出参与审批的人员及其邮箱：

| 角色 | 姓名 | 邮箱 | 备注 |
|------|------|------|------|
| 直属主管 | 例如：李四 | li.si@company.com | |
| 部门经理 | 例如：王五 | wang.wu@company.com | |
| HR负责人 | 例如：赵六 | zhao.liu@company.com | |

**如何获取准确的邮箱？**

**步骤 1：** 打开 Outlook 或 Outlook 网页版
```
URL: https://outlook.office365.com
```

**步骤 2：** 在搜索框中输入人名

**步骤 3：** 点击搜索结果查看完整邮箱地址

**步骤 4：** 复制邮箱地址保存下来

---

### 6. SharePoint 站点准备

**您需要一个 SharePoint 站点来存储应用数据。**

**选项 A：使用现有的 Team Site**
- 如果公司已有 SharePoint Team Site，可以直接使用
- 获取站点 URL，例如：`https://company.sharepoint.com/sites/HR`

**选项 B：创建新的 Team Site**

**步骤 1：** 打开 SharePoint 主页
```
URL: https://[company-name].sharepoint.com/
```

**步骤 2：** 点击左上角 "+ 创建站点"

**步骤 3：** 选择 "Team site"

**步骤 4：** 填写站点信息：
```
网站名称：加班申请审批
网站别名：overtime-approval
或其他您喜欢的名称
描述：用于加班申请和审批流程
```

**步骤 5：** 点击"下一步"，完成创建

**步骤 6：** 记下站点 URL
```
例如：https://company.sharepoint.com/sites/overtime-approval
```

**这个 URL 在后面的步骤中会用到！**

## 🚨 遇到问题？

### 问题 1：无法访问 make.powerapps.com

**症状：** 页面显示"无法连接"或"禁止访问"

**解决方案：**
1. 检查网络连接是否正常
2. 检查浏览器是否已登录公司账户
3. 清除浏览器缓存后重试
4. 如果仍然无法访问，联系 IT 部门

### 问题 2：没有看到 Power Apps 许可证

**症状：** 在 Microsoft 365 管理中心看不到 Power Apps 许可

**解决方案：**
1. 确认已使用正确的公司账户登录
2. 联系公司 IT 部门或 Microsoft 365 管理员
3. 告诉他们需要启用以下服务：
   - Power Apps for Office 365
   - Power Automate for Office 365
4. 通常需要 5-15 分钟启用

### 问题 3：无法创建 SharePoint 站点

**症状：** 没有看到"+ 创建站点"按钮或显示"无权限"

**解决方案：**
1. 使用现有的 Team Site（如果公司有的话）
2. 联系 SharePoint 管理员请求权限
3. 或者联系 IT 部门为您创建一个新站点

### 问题 4：浏览器显示警告或安全错误

**症状：** 页面显示"不安全连接"或"证书错误"

**解决方案：**
1. 这通常是企业防火墙或代理的问题
2. 检查您的网络连接和代理设置
3. 联系 IT 部门或网络部门寻求帮助

## 💡 额外建议

### 为了顺利部署，建议您：

1. **创建一个测试账户**
   - 用于测试应用和流程
   - 不用真实员工数据
   - 避免影响生产数据

2. **准备清晰的员工列表**
   - 员工姓名
   - 所属部门
   - 职位
   - 直属主管（非常重要！）
   - 邮箱地址

3. **列出审批人**
   - 各部门的主管和经理
   - HR 负责人
   - 获取他们的准确邮箱

4. **联系 IT 部门**
   - 告诉他们您要部署一个加班申请系统
   - 询问是否需要特别的许可或审批
   - 让他们提前做好准备
