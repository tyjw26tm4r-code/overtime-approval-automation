# SharePoint List 设置指南

在这一步，我们将创建 SharePoint List 来存储所有加班申请和审批流程数据。

---

## 📋 概述

**SharePoint List 是什么？**
- 一个在线数据表格，类似 Excel
- 但功能更强大，支持复杂的数据关系
- 完全整合到 Power Apps 和 Power Automate
- 可以多人同时编辑，自动保存版本

**我们需要创建哪些 List？**

| List 名称 | 用途 | 主要字段 |
|---------|------|--------|
| **OvertimeRequests** | 存储加班申请 | 申请人、申请日期、原因、时间等 |
| **ApprovalHistory** | 存储审批记录 | 申请ID、审批人、审批意见、审批时间 |

---

## 🚀 操作步骤

### 第一步：打开 SharePoint

**步骤 1：** 打开浏览器，访问 SharePoint 主页
```
URL: https://[company-name].sharepoint.com/sites/[your-site-name]
```

**步骤 2：** 如果您还没有 Team Site，请先创建一个

**步骤 3：** 进入站点主页

---

### 第二步：创建"加班申请"List

**步骤 1：** 在 SharePoint 站点上，点击左侧菜单中的 "+ 新建"

```
显示如下菜单：
+ 新建
  ├─ 列表
  ├─ 文档库
  └─ 页面
```

**步骤 2：** 点击 "列表"

**步骤 3：** 选择 "从空白列表创建"

**步骤 4：** 输入列表名称和描述

```
列表名称：OvertimeRequests
描述：加班申请信息表，包含申请人、申请日期、加班原因、审批状态等
```

**步骤 5：** 点击"创建"

---

### 第三步：为"加班申请"List 添加列

创建好 List 后，需要添加列字段。

**添加以下列：**

| 列名称 | 列类型 | 说明 | 必填 |
|------|------|------|------|
| **申请人邮箱** | 单行文本 | 员工邮箱 | 是 |
| **申请人名** | 单行文本 | 员工姓名 | 是 |
| **部门** | 单行文本 | 员工部门 | 是 |
| **加班日期** | 日期和时间 | 加班的日期 | 是 |
| **开始时间** | 单行文本 | 加班开始时间(HH:MM) | 是 |
| **结束时间** | 单行文本 | 加班结束时间(HH:MM) | 是 |
| **加班原因** | 多行文本 | 加班的具体原因 | 是 |
| **预计补休或加班费** | 选项 | 补休、加班费、其他 | 是 |
| **申请时间** | 日期和时间 | 自动设为当前时间 | 否 |
| **主管审批状态** | 选项 | 待审批、已批准、已拒绝 | 否 |
| **主管审批意见** | 多行文本 | 主管的意见 | 否 |
| **经理审批状态** | 选项 | 待审批、已批准、已拒绝 | 否 |
| **经理审批意见** | 多行文本 | 经理的意见 | 否 |
| **HR审批状态** | 选项 | 待审批、已批准、已拒绝 | 否 |
| **HR审批意见** | 多行文本 | HR的意见 | 否 |
| **最终状态** | 选项 | 待审批、已批准、已拒绝 | 否 |

**添加列的步骤：**

1. 点击列表标题右侧的 "+" 按钮
2. 选择 "新建列"
3. 填写列信息
4. 点击"创建"
5. 重复以上步骤为所有列

**设置选项类型的步骤：**

以"主管审批状态"为例：

1. 列名：`主管审批状态`
2. 列类型：选择 `选项`
3. 填写选项值：
   ```
   待审批
   已批准
   已拒绝
   ```
4. 设置默认值为 `待审批`
5. 点击"创建"

---

### 第四步：创建"审批历史"List

重复以上步骤创建第二个 List。

**步骤 1：** 点击 "+ 新建" → "列表"

**步骤 2：** 输入列表信息

```
列表名称：ApprovalHistory
描述：审批流程历史记录
```

**步骤 3：** 为 List 添加以下列：

| 列名称 | 列类型 | 说明 |
|------|------|------|
| **申请ID** | 单行文本 | 对应 OvertimeRequests 的 ID |
| **申请人名** | 单行文本 | 员工姓名 |
| **审批级别** | 选项 | 直属主管、部门经理、HR |
| **审批人** | 单行文本 | 审批人员名称 |
| **审批结果** | 选项 | 批准、拒绝 |
| **审批意见** | 多行文本 | 审批人的意见 |
| **审批时间** | 日期和时间 | 审批的时间 |
