# 邮件通知模板

本文档包含系统中使用的所有邮件通知模板。

---

## 📧 邮件模板总览

| 邮件类型 | 收件人 | 触发条件 | 优先级 |
|---------|------|--------|--------|
| 新申请通知 | 直属主管 | 员工提交申请 | 高 |
| 批准通知 | 员工 | 所有审批人都批准 | 高 |
| 拒绝通知 | 员工 | 任何审批人拒绝 | 高 |
| 审批提醒 | 审批人 | 24小时未审批 | 中 |
| 待审批提醒 | 审批人 | 流程卡在当前层 | 中 |

---

## 1️⃣ 新申请通知给直属主管

### 邮件主题

## 📝 邮件自定义建议

### 颜色和样式
- 批准邮件：使用绿色（#00B050）
- 拒绝邮件：使用红色（#C55A11）
- 待审批邮件：使用蓝色（#0078D4）

### 公司品牌
- 在所有邮件顶部添加公司 Logo
- 在底部添加公司联系方式
- 使用公司标准字体和颜色

### 链接配置
- 所有审批链接应直接指向系统中的申请
- 链接应包含申请ID和直接审批选项
- 测试链接确保有效
