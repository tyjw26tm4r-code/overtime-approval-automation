## 提交加班申请

### 完整步骤

**步骤 1：** 登录系统后，点击 "新申请" 或 "提交新申请"

**步骤 2：** 填写申请表

表单包含以下字段：

```
【申请人信息】（自动填充）
申请人名：张三（自动）
部门：销售部（自动）
邮箱：zhangsan@company.com（自动）

【加班信息】（需要填写）
加班日期：* 选择日期（必填）
开始时间：* 输入时间，如 09:00（必填）
结束时间：* 输入时间，如 18:00（必填）
加班原因：* 填写为什么需要加班（必填）

【补偿选择】（需要填写）
补休或加班费：* 选择补休或加班费（必填）
```

### 填写示例

```
加班日期：2024年6月15日
开始时间：14:00
结束时间：17:00
加班原因：处理紧急客户问题，需要完成项目验收
补休或加班费：补休
```

**步骤 3：** 检查所有信息

- [ ] 所有必填字段都已填写（*标记）
- [ ] 时间格式正确
- [ ] 原因描述清晰
- [ ] 选择了正确的补偿方式

**步骤 4：** 点击 "提交申请"

**步骤 5：** 等待确认

看到以下提示表示提交成功：
```
✓ 申请已成功提交！
您的申请ID为：OT-20240615-001
```

## 查看申请进度

### 查看我的申请

**步骤 1：** 登录系统

**步骤 2：** 点击 "我的申请" 或 "申请列表"

**步骤 3：** 查看所有您提交的申请

### 申请列表包含信息

| 列 | 说明 |
|----|------|
| 申请ID | 唯一标识符，用于查询 |
| 申请日期 | 您提交申请的日期 |
| 加班日期 | 实际加班的日期 |
| 状态 | 当前审批阶段 |
| 操作 | 查看详情或修改 |

### 申请状态说明

```
待审批：✕ 正在等待某个审批人的批准
    └─ 可能的审批人：直属主管、部门经理、HR

已批准：✓ 所有审批人都批准了
    └─ 您可以按照批准的补偿方式安排补休或获得加班费

已拒绝：✗ 某个审批人拒绝了
    └─ 您可以修改申请后重新提交

已完成：✓ 申请处理完毕
    └─ 已存档在系统中
```

### 查看详细信息

**步骤 1：** 在申请列表中找到要查看的申请

**步骤 2：** 点击 "查看详情" 或申请ID

## 常见问题

### Q1：我如何知道我的申请在哪个审批阶段？

**A：** 您可以：
1. 登录系统点击 "我的申请" 查看状态
2. 查收邮件了解最新进度
3. 实时显示当前审批人和阶段

### Q2：如果我的申请被拒绝了怎么办？

**A：** 您可以：
1. 查看拒绝原因
2. 修改申请内容
3. 点击 "编辑" 修改相关信息
4. 重新提交申请
5. 流程将重新开始审批

或者：
1. 联系您的直属主管讨论
2. 了解为什么被拒绝
3. 根据建议修改后重新提交

### Q3：审批需要多长时间？

**A：** 
- 每层审批建议 24 小时内完成
- 三层审批一般 2-3 个工作日完成
- 如果超过 24 小时，系统会自动提醒审批人

### Q4：可以取消已提交的申请吗？

**A：** 
- 如果还未被任何人审批，可以点击 "删除" 取消
- 如果已被某人审批，无法删除，需要等待全部审批完成
- 如需帮助，联系您的 IT 部门

### Q5：如何修改申请？

**A：** 
- 如果申请还在 "待审批" 状态，您可以点击 "编辑"
- 修改需要的信息
- 点击 "保存" 或 "重新提交"
- 修改后审批重新开始

### Q6：为什么我收不到邮件通知？

**A：** 可能的原因：
1. 邮件在垃圾邮件中 - 请检查垃圾文件夹
2. 邮箱已满 - 清理邮箱容量
3. 邮箱地址不正确 - 检查系统中的邮箱地址
4. 流程出错 - 联系 IT 部门

### Q7：我可以同时提交多个申请吗？

**A：** 可以。每个申请独立处理，互不影响。

### Q8：申请的保留时间是多久？

**A：** 系统将永久保留您的申请记录，用于查询和统计。

## 💡 使用小贴士

### ✓ 最佳实践

1. **提前规划**
   - 尽早提交申请
   - 给审批人足够的时间

2. **清晰描述**
   - 详细说明加班原因
   - 帮助审批人快速决定

3. **及时跟进**
   - 关注邮件通知
   - 定期登录系统查看进度

4. **保存记录**
   - 保存批准邮件
   - 记录申请ID便于查询

### ❌ 常见错误

1. ❌ 填写时间格式错误（如 "14.30" 应为 "14:30"）
2. ❌ 加班原因太简短（应详细说明）
3. ❌ 忘记勾选补休或加班费
4. ❌ 提交后不关注邮件通知
