# Power Automate 审批流程配置

在这一步，我们将创建自动化流程来处理三层审批流程。

---

## 📋 概述

**这个流程做什么？**

当员工提交加班申请后：
1. 自动发送审批请求给直属主管
2. 主管批准后，自动发给部门经理
3. 经理批准后，自动发给 HR
4. 所有人批准后，通知申请人已批准
5. 任何人拒绝，通知申请人已拒绝

---

## 🚀 操作步骤

### 第一步：打开 Power Automate

**步骤 1：** 打开浏览器，访问 Power Automate

```
URL: https://make.powerautomate.com
```

**步骤 2：** 用公司账户登录

**步骤 3：** 点击左侧菜单 "创建"

---

### 第二步：创建新流程

**步骤 1：** 点击 "+ 新建流" → "自动化的云流"

**步骤 2：** 选择触发器

搜索并选择：**"当项目创建或修改时"** (SharePoint)

**步骤 3：** 配置触发器

```
网站地址：选择您的 SharePoint 站点
列表名：OvertimeRequests
```

**步骤 4：** 点击"创建"

---

### 第三步：添加条件判断

现在添加逻辑来判断审批流程。

**步骤 1：** 点击 "+ 新建步骤"

**步骤 2：** 搜索并添加 "条件"

**步骤 3：** 设置条件

```
选择值：申请时间
操作符：不为空
值：[空白]

或者简单的条件：
选择值：主管审批状态
操作符：等于
值：待审批
```

---

### 第四步：发送给直属主管

在条件的 "是" 分支中添加以下步骤。

**步骤 1：** 点击 "+ 新建步骤"

**步骤 2：** 搜索并添加 "批准"

注：如果看不到"批准"，可以使用 "发送邮件" 替代

**步骤 3：** 配置批准请求

```
批准类型：批准/拒绝 - 每个人都必须批准

分配给：[从 Excel 表格中查找申请人的直属主管邮箱]

标题：加班申请审批 - {申请人名}

详情：
申请人：{申请人名}
部门：{部门}
加班日期：{加班日期}
加班原因：{加班原因}

链接 URL：[SharePoint List 的链接]
```

**使用公式查找主管邮箱：**
```
LookUp(
    EmployeeInfo,
    邮箱 = [申请人邮箱],
    主管邮箱
)
```

---

### 第五步：处理直属主管的审批结果

**步骤 1：** 在批准步骤下添加条件 "+ 新建步骤" → "条件"

**步骤 2：** 设置条件

```
选择值：批准的响应
操作符：等于
值：批准
```

#### 如果主管批准

在 "是" 分支中：

**步骤 1：** 更新 SharePoint List 中的项目

```
操作：更新项
网站地址：SharePoint 站点
列表名：OvertimeRequests
项目 ID：[当前项目]
字段：
  主管审批状态：已批准
  主管审批意见：[批准的备注]
  主管审批时间：[当前时间]
```

**步骤 2：** 发送邮件给部门经理

```
收件人：[部门经理邮箱]
主题：加班申请转发审批 - {申请人名}
正文：
[类似主管审批请求的内容]
```

#### 如果主管拒绝

在 "否" 分支中：

**步骤 1：** 更新 SharePoint List

```
主管审批状态：已拒绝
主管审批意见：[拒绝的备注]
最终状态：已拒绝
```

**步骤 2：** 发送邮件通知申请人

```
收件人：{申请人邮箱}
主题：您的加班申请已被拒绝
正文：
申请人：{申请人名}
加班日期：{加班日期}
拒绝原因：{主管审批意见}

请登录系统查看详情。
```

---

### 第六步：部门经理审批

重复第四步和第五步的流程，但这次：

- 发送给部门经理
- 更新"经理审批状态"字段
- 如果批准，继续发给 HR
- 如果拒绝，更新最终状态为"已拒绝"

---

### 第七步：HR 最终审批

重复第六步的流程，但这次：

- 发送给 HR 负责人
- 更新"HR审批状态"字段
- 如果所有人都批准，更新最终状态为"已批准"
- 发送最终通知邮件给申请人

---

### 第八步：添加邮件通知

当流程完成时，发送邮件通知申请人。

**批准的通知邮件：**

```
操作：发送电子邮件 (Office 365 Outlook)

收件人：{申请人邮箱}
主题：✓ 您的加班申请已获批准

正文：
尊敬的 {申请人名}，

您的加班申请已获得所有审批人的批准。

申请详情：
- 加班日期：{加班日期}
- 加班时间：{开始时间} - {结束时间}
- 加班原因：{加班原因}
- 补休/加班费：{预计补休或加班费}

请登录系统查看完整详情：[系统链接]

谢谢！
```

**拒绝的通知邮件：**

```
操作：发送电子邮件 (Office 365 Outlook)

收件人：{申请人邮箱}
主题：✗ 您的加班申请已被拒绝

正文：
尊敬的 {申请人名}，

您的加班申请未通过审批。

申请详情：
- 加班日期：{加班日期}
- 拒绝原因：{审批意见}

请登录系统查看详情或与您的直属主管联系。

谢谢！
```

## 📊 流程逻辑图

```
应用提交
  ↓
触发流程
  ↓
发送给直属主管
  ↓
  ├─ 批准 → 发送给部门经理
  │           ↓
  │           ├─ 批准 → 发送给 HR
  │           │          ↓
  │           │          ├─ 批准 → 最终状态：已批准 → 通知申请人
  │           │          └─ 拒绝 → 最终状态：已拒绝 → 通知申请人
  │           │
  │           └─ 拒绝 → 最终状态：已拒绝 → 通知申请人
  │
  └─ 拒绝 → 最终状态：已拒绝 → 通知申请人
```

## 🧪 测试流程

**步骤 1：** 保存流程

**步骤 2：** 返回 Power Apps 应用

**步骤 3：** 提交一个测试申请

**步骤 4：** 检查以下内容

- [ ] SharePoint List 中是否创建了新项目
- [ ] 直属主管是否收到邮件通知
- [ ] 主管批准后，部门经理是否收到邮件
- [ ] 经理批准后，HR 是否收到邮件
- [ ] 所有人批准后，申请人是否收到"已批准"邮件
- [ ] 拒绝时是否正确更新状态

**如有问题：**
- 检查邮箱地址是否正确
- 检查 SharePoint List 和 Excel 的连接
- 查看流程的运行历史（点击"分析"或"运行历史"）
