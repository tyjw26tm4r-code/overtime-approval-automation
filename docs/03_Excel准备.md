# Excel 数据准备指南

在这一步，我们将准备员工信息的 Excel 文件，这个文件将被 Power Apps 和 Power Automate 使用。

---

## 📋 概述

**为什么需要 Excel？**
- 存储员工基本信息（名字、部门、邮箱等）
- 作为参考数据源，不需要频繁修改
- Power Apps 和 Power Automate 可以快速读取这些数据
- 比手动录入快得多

**Excel 文件存储位置：**
- SharePoint Online（推荐）
- OneDrive for Business

---

## 🚀 操作步骤

### 第一步：创建 Excel 文件

**步骤 1：** 打开 Excel Online

```
URL: https://www.office.com
或者
URL: https://excel.office.com
```

**步骤 2：** 登录您的公司账户

**步骤 3：** 点击"+ 新建空白工作簿"或"新建" → "Excel 工作簿"

**步骤 4：** 系统会创建一个新的 Excel 文件

**步骤 5：** 给文件取名

```
建议名称：EmployeeInfo 或 员工信息库
```

---

### 第二步：添加数据列

**步骤 1：** 在第一行添加列标题

在 A1 到 H1 单元格依次输入以下内容：

| A | B | C | D | E | F | G | H |
|---|---|---|---|---|---|---|---|
| 员工ID | 姓名 | 邮箱 | 部门 | 职位 | 直属主管 | 主管邮箱 | 状态 |

**步骤 2：** 设置表格格式

1. 选中第一行（A1:H1）
2. 点击菜单 "开始" → "格式化为表"
3. 选择一个表格样式
4. 点击"确定"

这样 Excel 会自动识别为表格格式，便于后续处理。

---

### 第三步：添加员工数据

**示例数据格式：**

| 员工ID | 姓名 | 邮箱 | 部门 | 职位 | 直属主管 | 主管邮箱 | 状态 |
|-------|------|------|------|------|--------|--------|------|
| E001 | 张三 | zhangsan@company.com | 销售部 | 销售员 | 李四 | lisi@company.com | 活跃 |
| E002 | 王五 | wangwu@company.com | 销售部 | 销售经理 | 赵六 | zhaoliu@company.com | 活跃 |
| E003 | 李四 | lisi@company.com | 销售部 | 销售总监 | 赵六 | zhaoliu@company.com | 活跃 |
| E004 | 赵六 | zhaoliu@company.com | 人力资源 | HR 总监 | 董事长 | chairman@company.com | 活跃 |

**输入数据：**

1. 从第二行开始输入数据
2. 每行代表一个员工
3. 注意数据的准确性，特别是邮箱

**重要字段说明：**

- **员工ID**：唯一标识，建议格式 E001、E002 等
- **姓名**：员工全名
- **邮箱**：公司邮箱地址，必须准确（用于发送审批通知）
- **部门**：所属部门
- **职位**：职位名称
- **直属主管**：员工的直接上级
- **主管邮箱**：直属主管的邮箱
- **状态**：活跃/离职

---

### 第四步：验证数据

**检查清单：**

- [ ] 所有必需字段都已填写
- [ ] 邮箱格式正确（xxx@company.com）
- [ ] 没有重复的员工 ID
- [ ] 所有主管的邮箱都是有效的
- [ ] 数据格式一致

**常见错误：**

❌ 邮箱格式错误：`zhang san@company` （应为 `zhangsan@company.com`）
❌ 邮箱缺少 @ 符号或域名
❌ 主管邮箱与员工邮箱重复
❌ 存在空行或不完整的数据

---

### 第五步：保存到 SharePoint

**步骤 1：** 在 Excel 中点击"文件" → "另存为"

**步骤 2：** 选择"上传位置"

```
应选择您的 SharePoint 站点
例如：company.sharepoint.com/sites/overtime-approval
```

**步骤 3：** 给文件命名并保存

```
建议名称：EmployeeInfo.xlsx
```

**步骤 4：** 复制文件的完整 URL

1. 右键点击文件
2. 选择"获取链接"或"复制链接"
3. 保存这个链接（后续会用到）

---

## 📊 批量导入数据

如果已经有一个包含员工信息的 Excel 文件，可以批量导入到 SharePoint List。

**步骤 1：** 打开 SharePoint 中的 EmployeeInfo List

**步骤 2：** 点击菜单 "导入" → "从 Excel 导入"

**步骤 3：** 选择您准备好的 Excel 文件

**步骤 4：** 系统会提示映射列

```
将 Excel 中的列与 SharePoint List 的列进行匹配
例如：
Excel 列 "姓名" → SharePoint 列 "员工名"
Excel 列 "邮箱" → SharePoint 列 "邮箱"
```

**步骤 5：** 完成映射后点击"导入"

## 🔄 后续维护

### 更新员工信息

**添加新员工：**
1. 在 Excel 中添加新的一行
2. 填写完整信息
3. 保存（自动同步到 Power Apps）

**修改员工信息：**
1. 在 Excel 中编辑相应单元格
2. 按 Enter 保存
3. 立即生效

**删除员工：**
1. 在 Excel 中选中整行
2. 右键选择"删除行"
3. 保存

建议每个月检查一次：
- [ ] 是否有新员工需要添加
- [ ] 是否有员工离职需要标记为"离职"
- [ ] 邮箱地址是否有变化
- [ ] 部门或职位是否有变化

## ⚠️ 常见问题

### Q1：Excel 数据是否会自动同步到 SharePoint List？

**A：** 不会自动同步。您需要：
1. 在 Excel 中维护员工数据
2. 定期手动或通过 Power Automate 流程更新 SharePoint List

### Q2：可以直接在 SharePoint List 中编辑员工信息吗？

**A：** 可以，但不推荐。建议：
1. 在 Excel 中维护数据（便于批量管理）
2. 通过导入功能同步到 SharePoint List
3. SharePoint List 主要用于存储申请和审批信息

### Q3：如何处理已经离职的员工数据？

**A：** 有两种方式：
1. **保留记录**：标记状态为"离职"，保留数据用于历史查询
2. **删除数据**：直接删除或存档到单独的"历史员工"表格

推荐使用第一种方式，便于审计和历史查询。

### Q4：主管邮箱需要每个员工都填写吗？

**A：** 是的，这很重要。因为：
1. Power Automate 需要准确的邮箱地址发送审批通知
2. 如果邮箱错误，审批人收不到通知
3. 定期检查确保邮箱地址有效
