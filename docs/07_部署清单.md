## 🚀 上线部署步骤

### 步骤 1：最后测试（1小时）

**全面测试流程：**

1. 使用测试账户登录 Power Apps
2. 填写完整的加班申请
3. 提交申请
4. 检查是否触发了审批流程
5. 以审批人身份登录审批
6. 批准申请
7. 检查最终结果是否正确

**测试情景：**
- [ ] 申请被全部批准
- [ ] 申请在某一层被拒绝
- [ ] 多个申请并行审批

---

### 步骤 2：用户权限配置（30分钟）

**为员工配置权限：**

1. 打开 Power Apps 管理中心
2. 添加应用用户
3. 为每个员工分配应用访问权限

**为审批人配置权限：**

1. 打开 SharePoint 站点
2. 为审批人添加权限
3. 确保他们可以查看和编辑申请

---

### 步骤 3：发布应用（30分钟）

**发布到生产环境：**

1. 打开 Power Apps Studio
2. 点击菜单 "文件" → "发布"
3. 选择 "发布此版本"
4. 检查应用是否已发布

**共享应用：**

1. 点击菜单 "文件" → "设置"
2. 点击 "共享"
3. 添加用户或组
4. 设置权限为"使用"（不是"编辑"）

---

### 步骤 4：通知用户（1小时）

**发送通知邮件：**

```
主题：新的加班申请系统上线了！

尊敬的同事，

我们很高兴地宣布，新的加班申请系统现已上线！

新系统特点：
- ✓ 在线提交，不需要纸质表单
- ✓ 自动审批，流程更快
- ✓ 实时追踪，随时了解进度
- ✓ 邮件通知，不会错过提醒

如何使用：
1. 点击以下链接访问系统：[应用链接]
2. 登录您的公司账户
3. 填写加班申请表
4. 点击提交
5. 在邮箱中等待审批结果

常见问题：
[常见问题链接]

需要帮助？

感谢您的配合！
```

**为审批人发送特别通知：**

```
主题：重要：您需要审批加班申请

尊敬的 [审批人名]，

您已被指定为本系统的审批人。

您的职责：
- 及时审批下属的加班申请（建议 24 小时内）
- 填写审批意见
- 批准或拒绝申请

当有新的申请时，您会收到邮件通知。
您可以直接在邮件中点击"批准"或"拒绝"，或登录系统进行操作。

审批期限：
建议在收到申请后 24 小时内完成审批。

有任何问题，请联系：[IT 部门联系方式]
```
