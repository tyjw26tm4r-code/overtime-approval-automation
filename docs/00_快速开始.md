# 快速开始指南（5分钟）

## 🎯 这个系统做什么？

想象一下这个场景：

```
员工 张三 需要加班
      ↓
在 Power Apps 中填写表单
      ↓
自动发送给直属主管李四审批
      ↓
李四批准后，自动发给部门经理王五审批
      ↓
王五批准后，自动发给 HR 最终审批
      ↓
全部批准后，自动邮件通知张三
      ↓
完成！整个过程自动化，无需人工干预
```

**这就是本系统要实现的！**

## 📊 系统如何工作？

### 简化版流程

```
┌──────────────────────────────────────────────────┐
│  1️⃣ 员工填写加班表单（Power Apps）              │
│     - 输入加班日期、时间、原因                    │
│     - 系统自动获取员工信息                        │
└──────────────────────────────────────────────────┘
                        ↓
┌──────────────────────────────────────────────────┐
│  2️⃣ 数据保存到 SharePoint                        │
│     - 记录所有申请信息                            │
│     - 为审批做准备                                │
└──────────────────────────────────────────────────┘
                        ↓
┌──────────────────────────────────────────────────┐
│  3️⃣ 触发 Power Automate 自动流程                 │
│     - 读取 Excel 中的员工信息                     │
│     - 找出直属主管，发送审批通知                  │
└──────────────────────────────────────────────────┘
                        ↓
┌──────────────────────────────────────────────────┐
│  4️⃣ 直属主管审批                                 │
│     - 收到邮件提醒                                │
│     - 点击"批准"或"拒绝"                         │
│     - 结果保存到 SharePoint                       │
└──────────────────────────────────────────────────┘
                        ↓
┌──────────────────────────────────────────────────┐
│  5️⃣ 自动流转到部门经理                           │
│     - 如果主管批准，自动发给部门经理              │
│     - 部门经理审批                                │
└──────────────────────────────────────────────────┘
                        ↓
┌──────────────────────────────────────────────────┐
│  6️⃣ 自动流转到 HR                                │
│     - 如果部门经理批准，自动发给 HR               │
│     - HR 最终审批                                 │
└──────────────────────────────────────────────────┘
                        ↓
┌──────────────────────────────────────────────────┐
│  7️⃣ 通知申请人结果                               │
│     - 所有人都批准 → 发送"已批准"邮件            │
│     - 任何人拒绝 → 发送"已拒绝"邮件              │

```

## 💡 核心概念（初学者必读）

### 什么是 SharePoint List？
- 就是一个在线数据库表格
- 可以存储结构化数据（有固定的列）
- 比 Excel 更适合团队协作
- 可以直接在 Power Apps 中读写

### 什么是 Power Apps？
- 微软出的"无代码"应用开发工具
- 用拖拖拽拽就能创建漂亮的表单和应用
- 不需要写代码
- 直接连接到数据源（SharePoint、Excel等）

### 什么是 Power Automate？
- 微软的自动化流程工具
- 可以设置"如果...那么..."的规则
- 自动执行重复任务（如发邮件、更新数据等）
- 完全通过图形化界面配置

### 什么是审批流程？
- Power Automate 内置的高级功能
- 可以自动发送审批请求给指定人员
- 自动收集批准/拒绝反馈
- 自动执行下一步操作

## ❓ 常见问题

**Q：如果我卡住了怎么办？**
A：查看 [常见问题](08_常见问题.md)，里面有详细的故障排查指南。

**Q：我可以修改系统吗？**
A：完全可以！这就是 Power Apps 和 Power Automate 的优势 - 一切都可以通过 UI 修改，无需编程。

**Q：如果审批人不批准会怎样？**
A：流程会停止，申请保持在"待处理"状态，员工可以修改后重新提交。详见 [用户手册](09_用户手册.md)。

**Q：可以增加审批层级吗？**
A：可以！只需在 Power Automate 中添加额外的审批步骤。详见 [常见问题](08_常见问题.md)。
